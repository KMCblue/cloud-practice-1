Про застосунок

Цей вебзастосунок створено у хмарному середовищі GitHub Codespaces та розгорнуто за допомогою GitHub Pages.

Хмарні технології

  • GitHub — зберігання програмного коду
  • GitHub Codespaces — хмарне середовище розробки
  • GitHub Pages — розгортання вебзастосунку

Інформація про студента

Хмарний сервіс: Microsoft Azure

Microsoft Azure — це глобальна хмарна платформа, яка надає понад 200 продуктів та послуг для розробки, запуску та управління програмами в мережі центрів обробки даних.

Моделі послуг: IaaS, PaaS, SaaS. Приклади: Azure Virtual Machines, SQL Database.

Офіційний сайт: azure.microsoft.com
